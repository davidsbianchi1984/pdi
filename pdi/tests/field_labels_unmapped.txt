# status: backlog — 56 rows

# Request-model fields with no row in `i18n._FIELD_LABELS`, so a 422 that
# names one shows the API's identifier rather than the label on the form.
# Checked by test_the_refusal_names_the_field_on_the_form.py, and ratcheted.
#
# `_FIELD_LABELS` covers the fields a person types into a form. These are the
# rest: enum members a control sets, ids a client fills in from the resource
# it is already looking at, and flags a switch owns. A 422 naming one of them
# is a client bug rather than something a person mistyped.
#
# The identifier is the fallback on purpose. Inventing a word for a field
# nobody labels would be worse than the identifier a reader can at least
# match to the form in front of them.
#
# ## 0.46.4 — that last paragraph was doing two jobs
#
# "Nobody labels it" was the reason not to invent a word, and it quietly
# became the reason not to look. Forty of these rows had a control on a form
# and no label beside it: five bare selects, eight boxes carrying only a
# placeholder, and a date input with nothing at all. The label was added to
# the form and then ported into the table, in that order — the record's rule
# is that the sentence agrees with the form, and a form that says nothing
# leaves nothing to agree with.
#
# What is left is what the paragraph above always claimed: groups
# (`admin`, `preferences`, `workflow`), ids a client fills in from the row it
# is looking at, enum members, and flags.
#
