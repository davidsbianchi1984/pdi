# ## Two choices made in that table, and why
#
#   * **No formal/informal split.** 0.48.1 found QRME's console addressing a
#     German reader as *Sie* in 204 rows while its phones said *du* in 60 — one
#     product making two contradictory claims about the relationship. These
#     rows avoid the T–V distinction wherever the language allows it, so the
#     question does not arise and cannot drift.
#   * **Portuguese is pt-PT** — *ficheiro*, *ecrã* — matching the shells.
#
# ## Localizing a screen blinds the guards that grep it
#
# Wiring Guiding.tsx turned `test_the_guide_screen_keeps_both_of_its_refusals`
# red, and it was right to. That check makes sure the console keeps saying the
# two things the server insists on — that the guide has no face, and that it
# does no machine translation — and it did it by grepping the screen for the
# English. The sentence moved into `l10n.ts`; the screen still says it; the
# grep went blind.
#
#     asked     is this sentence in the screen file
#     mattered  does the screen say it, in every language it offers
#
# This is this audit's own shape arriving inside the audit's guards, and it is
# a hazard for every round that follows: **`test_the_door_and_the_wire.py`
# greps fourteen screens for sentences they must keep**, and each one of those
# greps goes blind the round its screen is localized. The fix is `_says()` in
# that file — the screen must ask for the key and the table must hold it in all
# ten languages, which is stricter than the grep it replaces, since that only
# ever proved the English existed. Every screen wired from here on has to bring
# its guards with it.
