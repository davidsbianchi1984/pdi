# English refusals — the sentences the vault says when it says no.
# Checked by test_the_vault_refuses_in_one_language.py, both directions, and
# ratcheted.
#
# A tenant picks a language. `_STRINGS` honours it in the console's chrome,
# `_PAGE_STRINGS` honours a stranger's browser on the recipient's page, and
# the recipient's own two refusals are localized at their route — `tr_page` on
# RECEIVE_NO and RECEIVE_REVOKED, from the round that gave the recipient a
# door at all.
#
# The tenant's refusals were English. All sixty, on an account where the
# language picker had been answered and every other surface honoured it.
#
#     asked     is the stranger answered in their language
#     mattered  is the tenant
#
# The direction is the reverse of the usual one and worth naming for that
# reason. Three rounds across these repositories found a stranger being served
# the language of somebody who had an account. Here the stranger's page was
# already right and the account-holder's was not — because the stranger's page
# was built as a localization problem from the start, and the vault's own
# refusals were never looked at as text a person reads.
#
# Eleven are translated now: every credential and key check, which is what any
# route can raise. These 49 are not, and pass through as English, which is a
# visible gap rather than a confident error.
#
# ## What this file does not cover
#
# **26 f-string refusals**, down from 30. Sentences built by
# interpolation cannot be keyed on their English source, because at the moment
# they are raised there is no English source — only a result.
#
#     asked     is the refusal a constant we can translate
#     mattered  is every part of it something we can translate
#
# `i18n.Templated` now carries the template and its slots alongside the
# finished English sentence, and 4 sites were converted. What decides
# whether a site can be is the *slot*, not the frame: a slot holding a token —
# `en, es, pt`, `openai` — is the same string in every language and is safe to
# drop into a translated frame; a slot holding prose is not, and a translated
# frame around an English slot is worse than an English sentence, because it
# reads as a bug in front of somebody who is already being told no.
#
# The mechanism refuses rather than guesses: a slot that fails the whitespace
# test keeps the whole refusal English, so a half-translated sentence is not
# something a future round can produce by accident. See
# `test_a_refusal_whose_english_is_not_a_constant`.
#
# Named here rather than counted in, so 49 cannot be read as the whole number.
#
# ## 1.5.x: the three a tenant actually reads
#
# Sixteen rows, sorted by the question this estate keeps arriving at from a
# different direction each time: who is standing in front of this sentence.
#
#     asked     is the refusal translated
#     mattered  is the reader a person or a program
#
# Three were read by a tenant and are translated now: the console's *no
# public address to visit*, and the two key-custody refusals a tenant admin
# meets when adopting or releasing a customer-managed key. Those are screens
# somebody navigates in a language they chose.
#
# The remaining thirteen are not the same kind of sentence, and translating
# them would be motion rather than work — recorded here so a later round does
# not spend itself finding that out again:
#
# **Six are wire-shape validation** — `'count' must be a positive integer`,
# `'day' must be YYYY-MM-DD`, `'fingerprint' must be 8 hex characters`,
# `'op' must be a string`, `'problems' must be a non-empty list`,
# `'status' must be an HTTP status code (0 for no answer)` — plus
# `an error report is an object` and `each problem is an object`. They quote
# a JSON field name and name a format. The reader is whoever wrote the caller,
# and if the console raises one it is this product's own bug: the field name
# is English either way, and a translated frame around it helps nobody.
#
# **Two are programming errors** — `PDIClient needs base_url or an injected
# client` and its QRME twin. These cannot reach an end user at all; they fire
# when a developer constructs a client wrong.
#
# **Two are operator configuration** — `PDI_MASTER_KEY must be base64 of 32
# bytes` and `provider must be 'held' or 'kms'`. Same reasoning the
# PDI_ADMIN_TOKEN sentence below was exempted on, and it is recorded there
# rather than restated: the fix is the name of an environment variable.
#
# This is the same sort QRME ran the same week on its own ledger, where the
# split was visitor against owner. Here it is person against program.
#
# ## What stays English by decision
