# English strings on the screens behind a translated tab bar, per shell.
# Checked by test_the_tabs_are_translated_and_the_screens_are_not.py, and
# ratcheted in both directions: the count may not rise, and the record may not
# sit more than 20 above the real number.
#
# This is a measurement, not a claim. The console guard in the QRME repo
# (test_the_nav_is_translated_and_nothing_behind_it_is.py) found forty-six
# translated sidebar labels in front of 1577 English screens and made the same
# choice: record it honestly rather than pretend.
#
#     asked     is the chrome localized
#     mattered  is anything behind the chrome localized
#
# The smallest of the three products and the same defect. The vault's tab bar
# reads *Bóveda*, *Auditoría*, *Transferencias*; the screens behind them are
# English.
#
# Nothing has been carved out by name here yet. The candidate is the transfers
# surface — the screens that move sealed records to another party — for the
# reason the sibling used to pick its alarm strings: those are the ones where
# not understanding changes what happens rather than merely what is known.
#
# The Windows count is the largest because that shell puts its wording in XAML
# attributes, which cannot be re-read when the language changes.

# **Corrected in 0.30.9.** The numbers first recorded here counted any string
# literal containing a letter, which counted format fragments like
# `"\(dim): \(n)%"` — whose only letters are variable names nobody reads — as
# English prose. Roughly seventy-five of them across the nine shells.
#
#     asked     does this literal contain letters
#     mattered  does this literal contain words a reader reads
#
# The ratchet caught it by firing on a card that had just been fully
# localized, which is a measurement saying the opposite of the truth. The
# counts below are what is actually unreadable.

# **Corrected in 0.47.1.** This repo's guard is the sibling's guard, copied,
# so it carried the same blind spot: a string chosen by a ternary — `cond ?
# "A" : "B"` — is not at the start of an argument list, and every pattern here
# looked only there. The widening is ported verbatim from the repo that found
# it, along with the two tests that hold it in place.
#
# The counts below rise by twelve. Nothing regressed; twelve strings were
# always there and could not be seen.

# **0.47.5 — the welcome screen, and the sign-out this shell never localized.**
#
# Welcome is the accountless screen: whoever reads it has no tenant yet, so the
# language cannot come from a stored setting. `L10n`'s own docstring in this
# repo has said since it was written that `DeviceLanguage()` is what an
# accountless surface must pass; this screen was never given it, and every
# reader on earth was greeted in English.
#
# Two more came off with it, both the shape the siblings already fixed:
#
# * the desktop's **Sign out** sits in `NavigationView.PaneFooter`, and the
#   loop that localizes the nav walks `Nav.MenuItems` — which the footer is
#   not one of. QRME found this in its own copy of the file at 0.46.9 and
#   JIM-mini at 0.47.2; this is the third product with the same nav, and the
#   table did not even hold the row.
# * the desktop's only **Refresh** button was hardcoded English, beside an
#   `action.refresh` row that had been translated into ten languages and asked
#   for by nobody.
#
# The Windows count also drops by ten that were never English prose: the
# language picker's ten items are endonyms — each language named in its own
# language — and they moved out of XAML attributes into a table in the
# code-behind, where they read as the data they are.
#
#     asked     is this literal English
#     mattered  is this literal something a translator should touch

# **0.63.0 — the screens behind the tabs speak.** The whole surface in one
# round rather than a bite: the vault, the audit chain, the robots, the
# connectors, the admin card, the feedback card and the problem-reporting
# notice now read from the ten-language tables on all three shells, and the
# Windows pages moved their wording out of XAML attributes into the
# code-behind so it can be re-read when the language changes.
#
# The rows arrived checked, the way the split-wordings file said they would
# have to: where one shell already held a row the others hardcoded (the
# Android admin and record keys, the Windows problem-reporting and
# so-far rows), the existing row was copied verbatim and asked everywhere,
# rather than minted again. Where the console already said the same English
# (Disconnect, Platform, Snapshot, Hide, Seal record), the native rows carry
# the console's translations verbatim. The one wording that differed between
# shells — iOS's "written to a tamper-evident audit chain" against the other
# two's "hash-chained in the audit log" — was unified rather than translated
# twice.
#
# What stays, named: `provider:`/`v…` version fragments (identifier prose a
# reader treats as data), the transfer arrow line and filename fallback
# (format fragments whose letters are variable names), the Welcome server
# URL default, and the extractor's own truncations of interpolated strings.
# A floor with names, not a backlog with a number.
