# Patents — PDI

PDI is the custody layer for two products with published applications, and
it carries no separate filing of its own in this repository. The filings
live with the products they name:

| Product | Application | Publication | Where |
|---|---|---|---|
| JIM-mini | U.S. 19/038,196, priority January 25, 2024 | US 2025/0246290 A1 | [jim-mini/docs/patents](https://github.com/davidsbianchi1984/jim-mini/tree/main/docs/patents) |
| QRME | U.S. 19/056,418, priority February 20, 2024 | US 2025/0265659 A1 | [qrme/docs/patents](https://github.com/davidsbianchi1984/qrme/tree/main/docs/patents) |

This folder replaces the invention disclosure that used to live at
`docs/invention-disclosure.md`. The vault's own mechanisms — the
individually keyed vault, custody as a plan property, bequests that begin
at attestation, the resident inside the vault's process — are set out on
[docs/examination.md](../examination.md), each with the structure as built
and the test that holds it.
